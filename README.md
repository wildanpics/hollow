# HOLLOWBORN Discord Bot

Bot Discord resmi server **HOLLOWBORN**, mencakup:
- 🎙️ **Emperor Voice Verification System** (`/verification-setup`, `/verification-status`, `/verification-cancel`): Sistem verifikasi suara militer otomatis dengan antrean waiting room dan audio transmisi kaisar.
- 📜 **Server Protocol Navigator** (`/protocol-setup`): Embed protokol resmi interaktif HOLLOWBORN dengan navigasi bab dan switch bahasa Inggris/Indonesia.
- 🎨 **Tactical Welcome & Leave Canvas**: Banner selamat datang bergaya militer taktis dengan avatar member dan identitas operative.
- 🏆 **Survivor Profile & Voice Leaderboard**: Canvas profil taktis survivor dan papan peringkat aktivitas suara (podium wreath & crown).
- 🎮 **Sistem Mabar 2-Klik (Anti-Misskom)** (`/mabar`): Tombol cepat penjadwalan mabar dengan hitungan mundur live dan RSVP kehadiran.
- 🛡️ **Role Generator & Presets** (`/role-preset`, `/role-grant`, dll.): Manajemen role dan sistem izin server.
- 📋 **Daftar Perintah Otomatis** (`/commands`, `/help`).

---

## 🚀 Perintah Utama

### 1. Verifikasi Suara Kaisar (Voice Verification)
- `/verification-setup` : Memasang pesan embed verifikasi suara militer di channel tujuan.
- `/verification-status` : Melihat antrean dan status operasional sistem verifikasi.
- `/verification-cancel` : Membatalkan sesi verifikasi aktif bila terjadi kendala.

### 2. Protokol Server (Server Protocol)
- `/protocol-setup` : Mengirim embed resmi peraturan server HOLLOWBORN dengan menu dropdown bab.

### 3. Komunitas & Gaming
- `/mabar` : Buat jadwal mabar cepat dengan notifikasi dan tombol RSVP.
- `/profile` : Tampilkan kartu identitas survivor taktis.
- `/leaderboard` : Tampilkan podium top survivor dengan jam suara terbanyak.
- `/queue` : Cek posisi antrean verifikasi suara.
